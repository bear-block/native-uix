# Sponsor Native UIX

Native UIX is MIT licensed and experimental. Sponsorship supports maintainer
time to build native controls and navigation, verify platform behavior, and
publish clear implementation limits. The library has no paid feature tier.

## Support the maintainer

- [GitHub Sponsors](https://github.com/sponsors/bear-block) — recurring or one-time support through bear-block's existing sponsorship account.
- [Buy Me a Coffee](https://buymeacoffee.com/bearblock) — another way to support the maintainer.

These are the same maintainer channels used by
[Callx](https://bear-block.github.io/callx/sponsor), not a separate Native UIX
fund or a claim that donations are automatically allocated only to this project.
For project-specific support, mention Native UIX when contacting the maintainer.
Payment amounts and any current account-level benefits belong to those platforms;
this page does not invent new sponsorship tiers or service commitments.

## What support helps fund

| Priority | Work | Visible outcome |
| --- | --- | --- |
| Native implementation | UIKit and Material/Compose components, platform defaults and behavior contracts | Working example scenarios with explicit API boundaries |
| Compatibility verification | RN upgrades, minimum/current OS testing and a selected Expo native-build candidate | A version matrix backed by executed builds and interactions |
| Accessibility and devices | VoiceOver/TalkBack, large text, RTL, gestures, keyboards and physical-device checks | Documented results and fixes for verified gaps |
| Maintenance | Dependency upgrades, issues, regression checks and native lifecycle changes | Reproducible checks and releases when ready |
| Documentation | Specs mapping, missing coverage and future captures | Developer-facing guidance tied to implemented behavior |

Sponsorship does not imply complete Expressive coverage, production readiness,
measured performance, a guaranteed delivery date or acceptance of a requested
feature. Public priorities and technical review still apply. There is no current
Native UIX-specific SLA, paid support package or guaranteed sponsor benefit.

## Help without donating

Run the example on your own device and
[report results](https://github.com/bear-block/native-uix/issues). Include source
revision, RN/React versions, OS/API, device, build mode, scenario, expected result
and actual behavior. Avoid posting credentials or private application data.

Review the [compatibility policy](reference/COMPATIBILITY.md),
[open component/spec coverage](project/coverage.md) and
[contribution guidance](CONTRIBUTING.md). Capture publication remains deferred.
